# Assets

Miejsce na własne zasoby wizualne projektu:
- zdjęcia płyt głównych,
- przygotowane warstwy i overlaye,
- ikony i elementy interfejsu,
- grafiki pomocnicze do map diagnostycznych.

Do repozytorium powinny trafiać wyłącznie materiały, do których mamy prawa lub jednoznacznie udokumentowaną zgodę/licencję.
