# Modules

Wspólne moduły funkcjonalne Modi Diagnostic Lab dla map Xbox 360.

Pierwszy plan:
- board-map — interaktywna mapa płyty,
- component-search — wyszukiwarka elementów z auto-zoomem,
- power-rails — linie zasilania i trasy,
- measurements — szybkie pomiary i oczekiwane wartości,
- rrod — odczyt i dekodowanie kodów RROD,
- psu — diagnostyka zasilacza i zasilania standby.

Ten katalog na razie definiuje podział funkcjonalny; implementacje będą dodawane wraz z rozwojem projektu.
