# Modi Diagnostic Lab — Xbox 360 Diagnostic Maps

Publiczna baza map diagnostycznych i materiałów serwisowych dla konsol Xbox 360, rozwijana jako część projektu **Modi Diagnostic Lab**.

## Zakres startowy

- Trinity
- Corona
- Jasper
- Winchester
- dekoder RROD
- linie zasilania i punkty pomiarowe
- wyszukiwarka komponentów
- dokumentacja źródeł i licencji

Projekt jest rozwijany etapami. Struktura repozytorium została przygotowana tak, aby kolejne modele, mapy i narzędzia można było dodawać bez przebudowy całości.

Zobacz `docs/PROJECT_TREE.md`, aby sprawdzić pierwszy podział projektu.
