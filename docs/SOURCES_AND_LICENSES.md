# Sources and licenses

Ten plik będzie zawierał listę źródeł wykorzystanych przy przygotowaniu map diagnostycznych oraz informacje o licencjach.

Każdy nowy materiał powinien mieć zapisane:
- nazwę źródła,
- autora lub właściciela,
- link lub identyfikator materiału,
- zakres wykorzystania,
- status licencji / zgody,
- datę weryfikacji.

Materiały bez potwierdzonego źródła należy oznaczać jako `UNVERIFIED` do czasu weryfikacji.
